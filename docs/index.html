    Which Artifact Should I Install?

    Non-Root (Standalone APK)

    Download any Standalone APK and install it directly on Android. Google apps (YouTube, YouTube Music, Google Photos) also require MicroG installed for account sign-in.

    Rooted (Magisk / KernelSU / APatch)

    Download a Single Root Module or Multi-App Bundle .zip, flash it in your root manager, and reboot. Use Copy OTA URL to paste the update feed URL into KernelSU/Magisk.

    Build Your Own Selection

    Open Custom Build to pick exact apps and architectures, copy a local revancex CLI command, or dispatch a custom GitHub Actions workflow.
